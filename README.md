# MailTracer
Spring boot Rest Api application for SV Profi

Stack: Java 11, Maven, Swagger, RestApi, SpringBoot, SpringData, PostgreSQL, Junit 5, Liquibase, Docker

Run project(go to project dir MailTracer):
- docker-compose up (run postgesql container)
- open project in intellijIdea run mvn purposes clean compile
- push run
